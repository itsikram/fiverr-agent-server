================================================================================
WHAT THE TEST DOES:
================================================================================

1. Checks MongoDB connection and collection existence
2. Verifies server health (/health endpoint)
3. Creates a test user and gets authentication token
4. POSTs activity data to /activities endpoint
5. GETs activities from /admin/activities endpoint
6. Validates that data is stored in MongoDB

IF TESTS FAIL:
================================================================================

Common Issues:

1. Server not running:
   Error: "Is the server running on port 8765?"
   Fix: Run "npm start" in Terminal 1

2. MongoDB not accessible:
   Error: "MongoDB connection failed"
   Fix: Check .env file for MONGODB_URI
   Test: mongosh "mongodb+srv://testmailbd2026_db_user:BgAEQdfgnmdSuZKp@cluster0.gwqnbsp.mongodb.net/fiverr_agent"

3. Endpoints not found (404):
   Error: "/activities endpoint not found" or "/admin/activities endpoint not found"
   Fix: Read TEST_ACTIVITIES_README.md for implementation guide
   These endpoints need to be added to MessageServer.js

================================================================================
ENDPOINT REQUIREMENTS:
================================================================================

The test expects these endpoints to be implemented in MessageServer.js:

POST /activities
  - Accepts: Authorization header with Bearer token
  - Body: { category, action, detail, metadata }
  - Returns: 201 Created with activity object
  - Logs activity to MongoDB user_activities collection

GET /admin/activities
  - Accepts: Authorization header with Bearer token (admin only)
  - Query params: limit, userId, category, action, from, to
  - Returns: 200 OK with { activities: [...] }
  - Fetches activities from MongoDB user_activities collection

See TEST_ACTIVITIES_README.md for implementation guide and code examples.
